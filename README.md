# 着せ替えキーボード

写真を背景にできるiPhone用の英字キーボード（個人利用）。

現在は**確認用の最小版**です。本体アプリで選んだ色が、キーボードの背景に反映されるかだけを確かめます。

## iPhoneに入れる手順（Windows）

1. Appleの「Apple Devices」アプリ（またはiTunes）をWindowsに入れる
2. https://sideloadly.io からSideloadlyを入れる
3. GitHubのこのリポジトリ → Actions → 最新の成功したbuild → Artifacts の `PhotoKeyboard-ipa` をダウンロードして解凍
4. iPhoneをUSBでPCにつなぎ、iPhone側で「このコンピュータを信頼」
5. Sideloadlyに `PhotoKeyboard.ipa` をドラッグし、Apple IDを入力して Start
6. iPhone：設定 → 一般 → VPNとデバイス管理 → 自分のApple ID → 信頼
7. iPhone：設定 → プライバシーとセキュリティ → デベロッパモード をオンにして再起動（初回のみ。項目がなければ不要）
8. iPhone：設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → 着せ替えキーボード

## 確認すること

1. 本体アプリを開き、「共有フォルダ」が「使える」になっているか
2. 色を1つ選び、「設定値 OK / ファイル OK」と出るか
3. 下の入力欄をタップし、🌐 で着せ替えキーボードに切り替える
4. キーボードの背景が選んだ色になり、上部に「設定値: OK #…」または「ファイル: OK #…」と出るか
5. 文字・スペース・削除・改行・⇧・🌐 が動くか

7日たつとアプリが開かなくなるので、手順5をもう一度行う。
